# Process Creation and Synchronization Using fork() and wait()

### 1. Aim

To understand how a new process is created using the fork() system call and how the parent and child processes are synchronized using the wait() system call in the Linux operating system.

### 2. Theory

A process is a program that is currently being executed by the operating system. In Linux, process creation and management are important functions of the operating system.

The fork() system call is used to create a new process called a child process from an existing process called the parent process.

After calling fork(), two processes exist:

* Parent Process: The original process that creates the child process.
* Child Process: The newly created process.

Both processes execute independently. The fork() system call returns different values:

* 0 to the child process.
* Child's PID to the parent process.
* -1 if process creation fails.

### 3. Process Identification

Every process in Linux has a unique Process ID (PID). The getpid() system call is used to obtain the PID of the currently executing process. It helps identify the process running in the system.

### 4. Process Synchronization Using wait()

Process synchronization means controlling the execution of processes so that they execute in the required order.

The wait() system call is used by the parent process to wait until its child process terminates.

When the parent executes wait(NULL), it gets paused until the child process finishes execution. After the child terminates, wait() returns the PID of the terminated child process.

### 5. Process Termination

The exit(0) function is used to terminate a process successfully.

In this experiment, the child process uses sleep(2) to pause its execution for two seconds before terminating.

### 6. Working Principle

1. The program starts execution from the main() function.
2. The fork() system call creates a child process.
3. Both parent and child processes begin executing.
4. The child process displays its PID.
5. The child process pauses for two seconds.
6. Meanwhile, the parent process waits using wait(NULL).
7. After two seconds, the child process terminates.
8. The parent process resumes execution and displays the child's PID.
9. Finally, the parent process terminates.

### 7. Applications

1. Creating new processes in an operating system.
2. Managing multiple processes.
3. Running applications independently.
4. Synchronizing parent and child processes.
5. Preventing zombie processes by collecting child process termination status.

### 8. Conclusion

The fork() and wait() system calls are important Linux process management functions. fork() creates a child process, while wait() synchronizes the parent process with the child. This experiment demonstrates the basic concepts of process creation, execution and synchronization in Linux.
